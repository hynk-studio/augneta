# PR-02 — 촉각 출력과 지각 교정

기준: [원래 로드맵 §11](../PROJECT_SELECTION_AND_PROTOCOL.md#11-구현-순서-기반-문서만-있는-저장소를-만들지-않는다).
PR-01의 다음 단계다. WASD 조작을 다른 입력으로 바꾸는 작업이 아니라,
추정한 환경 정보를 실제 감각 출력으로 전달하고 구별 가능한지 확인하는 작업이다.

## 최초 준비 범위와 후속 확장

아래는 `2dc691a`의 최초 준비 범위다. 2026-10-15 후속 구현은
[TactSleeve 명세](TACTSLEEVE_INTEGRATION.md)의 5.0에 따라 진행하며,
[6슬롯 표현과 교정 리허설](../PREARRIVAL_PREPARATION.md)을 추가했다.

- 기존 `FeedbackPacket`에서 장치 명령으로 가는 독립 경계.
- 논리 8채널 → 서로 다른 액추에이터 인덱스, 채널별 4단계 명령 세기,
  출력 프로파일의 별도 ID와 내용 해시.
- 명시적 시작, 제한된 펄스, 만료·오래된 패킷·중복·중단 후 콜백 처리의 mock.
- 실제 인과 추정 패킷을 사용하는 실행 가능한 합성 출력 점검과 원본 추적 기록의 재생.
- 무작위 순서의 균형 잡힌 식별 계획, 무출력 문항, 누락을 보존하는 혼동표 계산.
- 공식 자료에 근거한 장치 후보와 웹 연결 방식, 실물 측정·교정 절차.

기본 출력 프로파일은 **mock 전용 값**이다. 현재 화면은 개발자용 시각 리허설이며,
촉각 드라이버·장치 연결·참가자용 실물 교정은 아직 없다. 이 PR을 병합해도
PR-02 전체가 완료되지는 않는다.

## 완료 기준

1. 장치·계정·추가 패키지 없이 두 새 CLI 명령이 실행된다.
2. 출력 경계가 숨은 정답·목표·행동을 받지 않고 기존 패킷과 부호 회전을 보존한다.
3. 중복 패킷은 펄스를 연장하지 않으며, 중단 후에는 새로 시작해야 한다.
4. 명령 수신과 물리적 측정을 별도로 기록하고 물리적 타임스탬프는 `null`로 남긴다.
5. 식별 계획의 정답은 운영자 자료로만 생성하고 가짜 참가자 응답을 만들지 않는다.
6. 잘못된 응답·누락·무출력 오탐을 숨기지 않는다. 임의의 성공 판정 기준을 만들지 않는다.
7. 실제 실행·실패·미검증 내용을 검증 기록에 남기고 Draft PR로 제안한다.

## 실물 단계에서 이어 할 일

선택한 장치와 버전을 고정한 뒤 드라이버, 실제 웹 연결, 착용 위치 확인,
출력 시작·종료 측정, 지각 교정 UI를 구현·검증한다. 장치가 없어 수행할 수 없는
항목을 소프트웨어 통과 결과로 대체하지 않는다.

실행 절차와 측정 항목은 [출력·교정 설계](../HAPTIC_OUTPUT_AND_CALIBRATION.md),
후보 선택은 [장치 검토](../HAPTIC_DEVICE_OPTIONS.md)를 따른다.
구매·실물 작동·사람 대상 수집은 장치와 수행 범위가 정해진 후 진행한다.
PR-03의 학습/전이 연구와 PR-04의 의미 보존 연구는 원래 순서를 유지한다.
