# 내 컴퓨터에서 P1 개인 점검 시작하기

**Mac에서 저장소 ZIP을 풀고 맨 위의 `Start-P1.command`를 실행하세요.** Python 3.12 이상이 필요합니다. 첫 실행은 전용 환경을 만들고 필요한 패키지를 설치합니다. 이후에는 인터넷 연결 없이 같은 파일로 두 방문을 열 수 있습니다. 터미널에서 실행할 때는 압축을 푼 폴더에서 아래 한 줄을 사용하세요.

```sh
sh ./Start-P1.command
```

브라우저가 자동으로 열리지 않으면 같은 컴퓨터에서 [개인 점검 화면](http://127.0.0.1:8013/)을 여세요. 훈련은 방향키·WASD 또는 화면 버튼으로 할 수 있습니다. 점검하는 동안 서버의 터미널 창을 열어 두세요.

1. **첫 방문.** 과제를 미리 본 정도를 선택하세요. 화면 안내에 따라 방향 8개를 연습하고 부표를 30초씩 두 번 조종한 뒤 관문 16개를 고릅니다. 원하면 관찰한 점을 적고 **첫 방문 저장**을 누르세요. 다음 방문 목표 시각이 나오면 창과 터미널을 닫아도 됩니다.
2. **약 24시간 뒤.** 같은 Mac 사용자 계정에서 같은 실행 파일을 다시 여세요. 서버가 이미 열려 있으면 기존 주소를 여세요. 추가 연습 없이 새 관문 16개와 마지막 8개를 풉니다. 목표 시각과 달라도 진행할 수 있으며 실제 간격이 기록됩니다.
3. **결과 확인.** 두 방문을 마치면 세 묶음의 점수가 각각 표시됩니다. **내 결과 JSON**으로 직접 저장할 수 있습니다. 다음에 함께 볼 때는 화면의 세 점수와 실제 간격, 조작하며 느낀 점만 적어도 됩니다.

이름이나 계정은 필요하지 않습니다. 연습 응답, 직접 조작, 선택과 시간, 선택적으로 적은 메모는 이 컴퓨터에 저장됩니다. 이 Mac 사용자 계정에서 점검을 열면 브라우저를 바꾸거나 쿠키가 사라져도 같은 기록이 열립니다. 기본 데이터 파일은 `~/Library/Application Support/Augneta/p1-self-v1.sqlite3`입니다. 공개 저장소나 외부 서버로 결과를 전송하는 기능은 없습니다.
